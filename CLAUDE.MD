## Project Overview

This is a **Crossplane AWS Demo** - a full-stack educational project demonstrating:
- **Infrastructure as Code**: AWS EKS cluster provisioned via Terraform
- **Declarative Cloud Infrastructure**: AWS resources (S3, RDS, IAM, DynamoDB) managed through Crossplane YAML manifests
- **Interactive Documentation UI**: React-based file browser displaying all configurations
- **Unified Kubernetes API**: Managing both applications and infrastructure through Kubernetes

## ⚠️ Issues Identified

### 1. **Security Issues**

| Issue | Severity | Impact |
|-------|----------|--------|
| `.tfstate` files committed to git | **HIGH** | Exposes AWS credentials, secrets, RDS passwords in version history |
| Hardcoded AWS region in manifests | **MEDIUM** | Not easily portable across regions |
| Missing IAM role least privilege policies | **MEDIUM** | Crossplane may have overly permissive access |
| Database password in plaintext YAML | **HIGH** | Should use Kubernetes secrets or AWS Secrets Manager |
| No .env secrets management in frontend | **MEDIUM** | GEMINI_API_KEY exposed if .env checked in |

**Recommendations:**
```bash
# Add to .gitignore immediately:
terraform/.tfstate*
terraform/.terraform/
terraform/.terraform.lock.hcl
.env
.env.local
```
